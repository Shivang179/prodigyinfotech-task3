# Decision Tree Classifier

## About the Project

This project was completed as part of my **Data Science Internship at Prodigy InfoTech**.

The objective of this project is to build a Decision Tree Classifier that predicts whether a customer will purchase a product or service based on demographic and behavioral information. The project includes data preprocessing, model training, prediction, and performance evaluation.

---

## Dataset

The project uses a customer marketing dataset containing features such as:

- Age
- Job
- Marital Status
- Education
- Balance
- Housing Loan
- Personal Loan
- Contact Type
- Previous Campaign Information
- Purchase/Subscription Status

---

2. Install the required libraries

```bash

```

3. Start Jupyter Notebook

```bash
jupyter notebook
```

4. Open the notebook and run all the cells.
